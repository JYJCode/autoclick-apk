# 오토클릭

Android 8.0 이상에서 사용할 수 있는 자동 클릭 앱입니다.

## 다운로드

[최신 APK 다운로드](https://github.com/JYJCode/autoclick-apk/releases/latest)

릴리스의 **Assets**에서 **.apk 파일**을 휴대폰으로 내려받아 기존 앱 위에 설치하세요. 앱에서 접근성 권한을 설정한 뒤 서비스를 시작하면 됩니다.

## 포함 기능

- v0.1.10: 업데이트 재확인·수동 확인·안내 상태 보존 개선
- 같은 주머니 위에서 두 손가락을 벌리거나 오므려 길이와 표적 간격 조절
- 양끝 길이 조절 버튼 제거; 회전·복사·삭제 버튼과 한 손가락 본체 이동 유지
- 함께 실행할 기본 앱은 **클래시 오브 클랜**이며 앱 설정에서 변경 가능; 기존 앱 선택은 유지
- 기본 바처스쿼드는 위쪽 5번·6번 주머니 두 개와 내부 표적 12개
- 주머니를 삭제하면 안의 표적도 함께 삭제하며 다른 주머니와 바깥 표적은 유지
- 주머니 안 표적을 복사하면 같은 주머니에 추가하고 동일 간격으로 배치
- 주머니를 더 늘릴 수 없는 화면에서는 기존 길이 안에서 간격 조정
- 이동 중 한 캔버스로 표시하고 표적이 없는 주머니 본체를 드래그해 함께 이동
- 전체 지점 최대 100개, 같은 순번 동시 클릭 최대 6개
- 클릭 횟수·간격·대기시간·길게 누르기 설정
- 카운트다운 기본 **0초**, 앱 설정에서 변경 가능
- 화면 크기·방향이나 조작 바 겹침으로 실행을 차단하지 않음
- 저장된 배치를 기본 틀로 불러오고 이용자가 직접 위치 조정
- 주머니 영역을 누르면 회전·복사·삭제 아이콘 표시
- 주머니 바깥을 누르면 조절 아이콘 숨기기
- 지점 표시·숨기기와 사이클 저장·불러오기
- 앱을 열거나 돌아오면 최신 버전을 확인하고 새 APK가 있으면 **나중에 / 다운로드** 안내 표시
- 메인 화면의 **업데이트 확인**으로 직접 재확인하고 현재 버전과 결과 확인
- 다른 화면에 다녀와도 업데이트 안내를 복원하며 확인 실패 시 다시 시도 가능

현재 저장한 사이클과 편집본은 업데이트 시 유지합니다. 기본 사이클은 새로 만들어지는 저장 목록에만 제공하며 기존 저장본을 덮어쓰지 않습니다. 기본 제공 사이클은 대략적인 틀이며, 설치한 기기에 맞는 위치는 직접 조정해 사용하세요.
