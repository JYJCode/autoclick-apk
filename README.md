# 오토클릭

Android 8.0 이상에서 사용할 수 있는 자동 클릭 앱입니다.

## 다운로드

[최신 APK 다운로드](https://github.com/JYJCode/autoclick-apk/releases/latest)

릴리스의 **Assets**에서 **.apk 파일**을 휴대폰으로 내려받아 설치하세요. 앱에서 접근성 권한을 설정한 뒤 서비스를 시작하면 됩니다.

## 포함 기능

- 전체 지점 최대 100개, 같은 순번 동시 클릭 최대 6개
- 지점별 클릭 횟수·간격·대기시간·길게 누르기 설정
- 주머니로 지점 정렬·길이 조절·회전·전체 복사
- 조작 바에서 지점 표시·숨기기와 사이클 저장·불러오기
- 다른 화면 크기·가로/세로 방향에서도 현재 화면 비율에 맞춰 사이클 불러오기
- 새 설치 시 **바처스쿼드** 저장본 포함: 지점 36개, 주머니 4개
- 앱을 열 때 최신 버전을 확인하고 새 APK가 있으면 **나중에 / 다운로드** 안내 표시

업데이트 확인에 실패하거나 이미 최신 버전이면 별도 알림 없이 앱을 사용할 수 있습니다. 다운로드 버튼은 공개 릴리스 페이지를 엽니다.

바처스쿼드는 저장 당시 화면 크기 **2208 × 1768**을 기준으로 저장돼 있습니다. 불러올 때 현재 화면이 다르면 편집본의 지점·주머니 위치를 맞추며, 저장된 원본과 클릭 설정은 유지합니다. 기존 저장 목록과 편집본은 업데이트 시 유지합니다.
