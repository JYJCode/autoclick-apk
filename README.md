# 오토클릭

Android 8.0 이상에서 사용할 수 있는 자동 클릭 앱입니다.

## 다운로드

[최신 APK 다운로드](https://github.com/JYJCode/autoclick-apk/releases/latest)

릴리스의 **Assets**에서 **.apk 파일**을 휴대폰으로 내려받아 기존 앱 위에 설치하세요. 앱에서 접근성 권한을 설정한 뒤 서비스를 시작하면 됩니다.

## 포함 기능

- **v0.1.23**: 주머니·표적 이동 처리 구조 교체. 움직이지 않는 그림은 재사용하고 이동하는 항목만 갱신
- 회전·길이 조절 시 선택한 주머니만 다시 그리고, 최신 터치 좌표를 프레임 단위로 처리
- 입력 창 재배치를 줄이고 위치 확정·저장은 손을 뗄 때 처리
- **v0.1.22**: 사이클 완료 후 금·엘릭서·다크엘릭서가 모두 가득 차면 정지하는 자원 인식 기능
- 계정 5개에 저장 사이클·최대 자원량을 설정하고 완료된 계정부터 다음 계정으로 자동 전환
- 공통 전환 동작과 계정별 선택 동작을 ＋로 추가하고 이동하는 표적 방식으로 편집
- 드래그 경로와 시간을 기록하며 손을 떼면 기록한 드래그를 한 번 자동 실행
- Android 13 이상에서 편집 그림·입력을 하나의 정적 창으로 통합하고 불필요한 표시 갱신 제거
- 자원 인식과 계정 자동 순환은 Android 11 이상에서 지원; 인식은 기기 안에서 처리하고 화면을 저장·전송하지 않음
- 모든 표적의 테두리·십자선을 흰색으로 통일하고 순번 색을 파스텔톤으로 변경
- 동일 순번 그룹은 파스텔 빨강→주황→노랑→초록→파랑→남색→보라 순으로 표시
- 기본 표적은 흰색 바탕·흰색 테두리·검정 번호로 표시; 같은 순번 그룹의 일곱 색은 반복
- 파스텔 표적의 번호는 검정으로 표시
- 업데이트 안내의 다운로드를 누르면 APK 파일 주소 바로 열기
- 기능 바 아래 주머니의 사각형 잘림 제거 및 바 표시 순서 수정
- 접기·펼치기 버튼을 패널 모양 아이콘으로 변경
- 편집 바를 접으면 펼치기 버튼 하나만 표시하며 다시 펼치면 기존 기능 표시
- 실행 중 재생·정지 소형 바는 최우상단 고정, 정지하면 편집 바 위치로 복귀; 편집 바와 접힌 바는 드래그로 이동
- 같은 주머니 위에서 두 손가락을 벌리거나 오므려 길이와 표적 간격 조절하고 비틀어 각도 조절
- 기존 회전·양끝 길이 조절 버튼 제거; 복사·삭제 버튼과 한 손가락 본체 이동 유지
- 주머니 그림을 잘라 나누지 않고 통째로 표시하고 기능 바를 그 위에 표시
- 함께 실행할 기본 앱은 **클래시 오브 클랜**이며 앱 설정에서 변경 가능; 기존 앱 선택은 유지
- 기본 바처스쿼드는 위쪽 5번·6번 주머니 두 개와 내부 표적 12개
- 주머니를 삭제하면 안의 표적도 함께 삭제하며 다른 주머니와 바깥 표적은 유지
- 주머니 안 표적을 복사하면 같은 주머니에 추가하고 동일 간격으로 배치
- 전체 지점 최대 100개, 같은 순번 동시 클릭 최대 6개
- 클릭 횟수·간격·대기시간·길게 누르기 설정
- 카운트다운 기본 **0초**, 앱 설정에서 변경 가능
- 화면 크기·방향이나 조작 바 겹침으로 실행을 차단하지 않음
- 저장된 배치를 기본 틀로 불러오고 이용자가 직접 위치 조정
- 주머니 영역을 누르면 복사·삭제 아이콘 표시하고 바깥을 누르면 숨기기
- 지점 표시·숨기기와 사이클 저장·불러오기
- 앱을 열거나 돌아오면 최신 버전을 확인하고 새 APK가 있으면 **나중에 / 다운로드** 안내 표시
- 안내창의 다운로드는 배포 페이지를 거치지 않고 실제 APK 파일 주소로 연결
- 메인 화면의 **업데이트 확인**으로 직접 재확인하고 현재 버전과 결과 확인

현재 저장한 사이클과 편집본은 업데이트 시 유지합니다. 기본 사이클은 새로 만들어지는 저장 목록에만 제공하며 기존 저장본을 덮어쓰지 않습니다. 기본 제공 사이클은 대략적인 틀이며, 설치한 기기에 맞는 위치는 직접 조정해 사용하세요.

배포 검증: APK 빌드 성공, Android Lint 오류·경고 0개, 기존 배포 APK와 같은 서명 확인 및 공개 다운로드 파일 해시 일치. 최신 수정본의 기능 테스트와 기기 성능 측정은 진행하지 않았습니다.
